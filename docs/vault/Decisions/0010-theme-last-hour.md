# ADR 0010 — Theme: The Last Hour, binding laws, class/champion split

**Date:** 2026-07-22 · **Status:** accepted · **Participants:** Jake + Claude

## Context
Jake paused hero deep dives on realizing names/themes ripped too hard from Guild Wars, and
sketched: multiverse + time, a tower hub, fantasy bending into sci-fi — worried it was
scattershot. Three frames were proposed (time-first / place-first / collision); Jake chose
**time-first** with the naming split.

## Decisions
1. **Frame: The Last Hour.** Dying multiverse; the Tower outside time recruits champions
   from every era for descents into dying timelines. Sci-fi is native: the future is just
   another era being eaten. Depth: Design/theme.md.
2. **Three binding laws** (the anti-scattershot mechanism): everything references time ·
   each unit is one era played straight (v1: 8 champions, 8 eras, no repeats) · the Tower
   is the constant (shops, banners, hub).
3. **Class/champion split** (TFT model): class names stay functional and board-readable
   (Bulwark, Cleric…); era-flavored champions wear them. Deep dives proceed on class
   mechanics; lore names layer per champion without blocking.
4. This frame is load-bearing, not paint: ghost bosses = Echoes of parallel timelines
   (async PvP made diegetic), acts = eras (visual identity), overtime storm = the Hour.

## Consequences
- Hero deep dives unblocked; each dive names its champion within an unclaimed era.
- Flavor-name candidates pending Jake's yes (NOT decided): currency gold→Sand · tiers
  Safe/Even/Greedy→Stable/Fraying/Collapsing · storm→the Waning.
- Act-as-era implies per-act monster/visual identity — content implication for the real
  content pass; scope-checked there, not expanded silently.
- Game title search comes later; "warband" remains the working title.
